# ⚽ أداة الاستيراد الذكي للفرق وتوليد CSV
### Smart Team Importer & CSV Generator

أداة ويب تفاعلية سريعة وذكية تعمل بدون أي خادم (Client-Side 100%)، مصممة لاستخراج أسماء الفرق والمنتخبات سواء تم نسخها من:
1. **جداول المباريات والمواعيد والنتائج** (مع حالات مثل "تبدأ قريباً"، "انتهت"، التوقيت "10:00 م"، إلخ).
2. **جداول الترتيب والمجموعات** في المواقع الرياضية (مثل كوورة، 365Scores، Sofascore، Flashscore، إكسل، ويكيبيديا).

وتقوم بتوليد ملف CSV مرتّب أبجدياً مع مسارات الصور بضغطة زر وبأعلى احترافية.

---

## 🌟 المميزات الاحترافية

- **⚽ دعم استيراد المباريات والمواعيد:**
  - تجاهل حالات المباريات تلقائياً (`تبدأ قريباً`، `انتهت`، `جارية الآن`، `مباشر`، `تأجلت`، إلخ).
  - تجاهل أوقات المباريات والتواريخ الصرفة (`10:00 م`، `22:30`، `اليوم`، `غداً`، إلخ).
  - تجاهل فواصل المباريات (`vs`، `ضد`، `-`، أسطر النتائج مثل `2 - 1`).

- **📊 دعم جداول الترتيب والمجموعات:**
  - حذف رؤوس الجداول تلقائياً (`فريق`، `لعب`، `فاز`، `تعادل`، `نقاط`، إلخ).
  - إزالة أسطر الإحصائيات والأرقام والنتائج الصرفة (`1 1 0 0 0 1:5 4 3`).
  - إزالة أرقام الترتيب من بداية الأسماء (`1 برشلونة` ⬅️ `برشلونة`).
  - تجاهل عناوين المجموعات والجولات (`مجموعة B`، `الجولة 1`).

- **🧠 المعالجة الذكية للنصوص المبتورة (Smart Truncation Merge):**
  - إذا تم نسخ الاسم مرتين وكان أحدهما مقطوعاً أو ناقصاً (مثل: `بوروسيا دورتموند` والسطر الآخر المبتور `بوروسيا دورتمو`)، يقوم النظام الذكي بدمجهما تلقائياً واختيار الاسم الأكمل دون تكرار!

- **🔤 فرز أبجدي لغوي ذكي:**
  - ترتيب أبجدي من أ إلى ي (أو عكسي من ي إلى أ أو الترتيب الأصلي).
  - خيار ذكي لتجاهل **(الـ)** التعريف عند الفرز الأبجدي لقوائم الفرق (مثلاً: *السعودية* ترتّب مع حرف السين، *الكويت* مع الكاف، *اليابان* مع الياء).

- **📂 خيارات تخصيص مسار الصور:**
  - تحديد اسم مجلد الصور المسبق (الافتراضي `teams_images/`).
  - اختيار صيغة وامتداد الصور (`.png`, `.webp`, `.jpg`, `.svg`).

- **💾 تصدير متوافق 100% مع Microsoft Excel:**
  - تصدير ملف CSV بترميز **UTF-8 with BOM** لضمان فتح الأسماء العربية في Excel بدون أي تشويه للخطوط.
  - خيارات سريعة: نسخ CSV للحافظة، نسخ قائمة الأسماء فقط، أو التصدير بصيغة JSON.

## 🚀 طريقة التشغيل المباشر

المشروع عبارة عن صفحة ويب قائمة بذاتها (`index.html`)، لا تتطلب تثبيت Node.js أو أي مكتبات خارجية:
1. انقر نقراً مزدوجاً على ملف `index.html` ليفتح في متصفحك مباشرة.
2. يمكنك تجربة الأزرار السريعة:
   - **⚽ نموذج المباريات**
   - **📊 نموذج جدول الترتيب**
   - **🏆 نموذج المجموعات**

---

## 🌐 النشر المجاني على GitHub Pages

1. ادخل على مستودعك في GitHub.
2. توجّه إلى تبويب **Settings** > ثم اختر **Pages** من القائمة الجانبية.
3. تحت قسم **Build and deployment** > اختر المصدر **Deploy from a branch**.
4. حدد فرع `main` والمجلد `/ (root)` ثم اضغط **Save**.
5. خلال دقائق سيعمل موقعك مباشرة على الإنترنت:  
   `https://<username>.github.io/<repo-name>/`
